# public/css/

Purpose
- Stylesheets used by EJS views. Contains Bootstrap overrides and custom layout/styling files.

How to edit
- Edit CSS files and refresh the browser (or use `npm run dev` with nodemon for server-side changes). If using a bundler, rebuild assets accordingly.

Common files
- `style.css` (project-specific custom styles)
- `bootstrap-overrides.css` (if present)
