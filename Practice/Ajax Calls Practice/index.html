Learn AJAX Calls with jQuery

This mini lab lets you run GET, POST, PUT, DELETE calls and inspect request/response details.

Configured for UsmanLive fake API: https://usmanlive.com/wp-json/api.

How this works:

1) Build URL = Base URL + Endpoint. If endpoint contains :id, it is replaced using Story ID input.

2) Call $.ajax({...}) with method, headers, and body.

3) For protected route, set header type to x-auth-token and provide token from login response.

4) Login helper tries to auto-detect token and fill the token box for you.
